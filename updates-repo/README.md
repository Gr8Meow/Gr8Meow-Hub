# Gr8Meow Hub - Updates

Public update channel of **Gr8Meow Hub**. It only holds:

- `apps.json` - the list of apps the Hub shows (the Hub reads it from the `main` branch)
- Releases - the Hub's own `Gr8MeowHub-windows-x64.zip` (+ `.sha256`), published by the build in the source repo

Source code: https://github.com/Gr8Meow/Gr8Meow-Hub
